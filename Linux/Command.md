### du
du(Disk Usage) 디스크 용량을 확인하는 명령어


```
du -sh /path/to/directory : 디렉터리 총 용량 확인
```


### ls

```
lsblk : 하드디스크, SSD, USB등 블록장치의 목록과 구조를 트리 형태로 보여주는 명령어

lspci : 운영체제에서 PCI버스와 연결된 하드웨어 장치 정보를 확인하는 명령어

lsusb : USB버스 정보와 연결된 장치 목록을 출력하는 명령어

lsof : 현재 시스템에 열려있는 모든 파일과 해당 파일을 사용 중인 프로세스 정보를 출력하는 명령어 
```

chown [옵션] [소유자]:[소유그룹] [파일 또는 디렉터리 경로]
